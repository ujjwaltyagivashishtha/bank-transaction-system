# TRANSACT Backend Ledger Service

Core financial double-entry ledger API built with Node.js, Express, and MongoDB.

## Quick Commands

### Run Integration Tests
```bash
npm test
```
Executes 52 automated tests across authentication, ownership enforcement, transfer atomicity, concurrency, sub-paise precision, reconciliation, and receipts.

### Run in Development
```bash
npm run dev
```

### Run in Production
```bash
npm start
```
